# AURA LUXE — Haute Beauty Studio & Bridal Salon Website

A premium, elegant, modern, and fully responsive website crafted for a luxury makeup studio and bridal salon.

---

## 🌸 Design Philosophy & Aesthetics

- **Color Palette:**
  - **Blush Pink:** `#FAF0EE`, `#F9E3E2`, `#F2C6C4`, `#A2413E`
  - **Champagne Gold:** `#FAF4E3`, `#E6CA65`, `#D4AF37`, `#B89228`
  - **Cream & Nude Beige:** `#FAF8F5`, `#FAF6F0`, `#F5EFE6`, `#8C7A6B`
  - **Rose Noir / Luxe Dark:** `#1C1819`, `#2D282A`
- **Typography:**
  - **Headings:** *Playfair Display* (Editorial serif elegance)
  - **Body:** *Poppins* (Crisp, clean legibility)
  - **Quotes / Accents:** *Cormorant Garamond* (Bespoke haute couture cadence)
- **Visuals:** High-resolution bridal and beauty editorial photography, subtle glassmorphism cards, golden glow accents, and smooth transitions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Development
```bash
# Run local dev server
npm run dev
```
The server will start at `http://localhost:3000` with instant hot-module replacement.

### Production Build
```bash
# Compile optimized production bundle
npm run build
```
Optimized assets are generated inside the `dist/` directory, ready to deploy to any hosting provider (Vercel, Netlify, Cloudflare Pages, GitHub Pages).

### Preview Production Build
```bash
npm run preview
```
